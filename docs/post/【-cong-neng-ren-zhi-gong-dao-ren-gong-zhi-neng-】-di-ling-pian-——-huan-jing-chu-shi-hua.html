配置WSL环境

主要用于隔离环境（防止误删文件和读取隐私），多开（方便重新配置新的环境）和不使用powershell这个坑
但是WSL所有发行版共享同一个 IP 和同一个网络栈，同时多开实例需要注意端口冲突。

一、添加实例

推荐使用 Ubuntu 24.04 ，比较稳定，其它随意，我这里起名 Zero , 寓意最初的环境

二、隔离环境

因为 WSL 并不是与 Window 宿主机完全隔离的，我们还需要一些配置来单方面隔离 WSL ，使其无法在文件系统上操作 Window 宿主机的文件，网络方面我们还是让其互通，方便 MCP 等

GUI操作

先点击右边按钮展开。

再点击右边按钮配置。

把 自动挂载磁盘，处理/etc/fstab，启用 Windows 交互，追加 Windows 路径 ,四个默认勾选全部取消掉，然后点击保存并重启发行版。

最终配置如下

或者文件操作

打开文件管理器

进入etc

打开wsl.conf编辑

添加

[automount]
enabled = false
mountFsTab = false
 
[interop]
enabled = false
appendWindowsPath = false

使用 PowerShell 重启

wsl --shutdown

需要注意的是笔者实测的时候有 BUG ，当 automount.enabled = false 和 mountFsTab = false 同时关闭就无法使用 Windows 的文件管理器浏览 \\wsl.localhost，经过搜索是一个 WSL1 历史遗留问题 Plan9 file server is never started on WSL2 when both automount.enabled and automount.mountFsTab are false, making \wsl.localhost inaccessible. 已经在 7月15日 修复。

目前 2026.9.15 的2.9.8预览版本已经修复这个问题，之前的版本应该都有这个问题，可以通过 wsl --version 查看自身版本遇到这个问题需要更新，使用wsl --update或者wsl --update --pre-release

但是如果你开启了 WSLg ，有可能出现"无法加载远程桌面服务ActiveX控件。请确保rdclientax.dll 在路径中。" 这个报错，这时候如果你还是想使用 WSLg ，目前只能回退到 2.7.10 ，这个问题暂时没看到解决办法。GUI 在 Windows 10 ltsc 2021 x64 19044.1288 上无法运行

现在有了 Releases · WslzGmzs/WSL-2.7.10-plan9-fix，两个我都要好吧。目前用着没什么问题，有问题再说吧。用法的话可以用安装包直接覆盖安装试试，我没测试过安装包（实测WSL Settings会没有打包，建议用下面的方法），我是安装官方的2.7.10，然后直接把C:\Program Files\WSL\tools文件夹下的init，initrd.img两个二进制文件给覆盖了，就没第一个问题了，至于第二个问题，不更新2.7.10就不管了

三、环境配置

点击打开进入终端

//刷新软件源列表然后升级已安装的软件包

sudo apt update && sudo apt upgrade -y

sudo apt full-upgrade -y

sudo apt autoremove -y

//清理 APT 下载软件时留下的旧缓存包

sudo apt autoclean
代理配置
  1. 获取 Windows 主机 IP
cat /etc/resolv.conf | grep nameserver | awk '{print $2}'
  1. 点击 WSL Dashboard 的侧栏网络进行配置，记得保存
  1. 重启实例可以通过下面命令看是否配置成功
env | grep -i proxy
  1. 如果报错了 Connection refused，记得看局域网代理有没有打开，一般默认是只监听127.0.0.1

实现硬件加速图形渲染

//安装 Mesa 图形工具集

apt install -y mesa-utils

在 .bashrc 或 /etc/profile 中加入环境变量

export GALLIUM_DRIVER=d3d12
export LIBVA_DRIVER_NAME=d3d12

需要注意的是多 GPU 环境可能需手动指定(例如，强制使用 NVIDIA 显卡)

export MESA_D3D12_DEFAULT_ADAPTER_NAME=NVIDIA

验证是否生效

glxinfo | grep "OpenGL renderer"
  • 若输出包含 OpenGL renderer string: D3D12 等字样，说明硬件图形加速已成功开启。但是多 GPU 环境看是不是自己主力 GPU
  • 若输出包含 llvmpipe，则是 CPU 软件渲染，启用失败。

如果 OpenGL 在英特尔 GPU 上依然使用 llvmpipe 软件渲染，则需要为 libedit 创建符号链接：

ln -s /usr/lib/libedit.so /usr/lib/libedit.so.2

配置中文语言环境（其它语言也可以参考）

设置中文语言环境

  1. 执行 locale 命令查看当前系统语言配置，如果是 LANG=zh_CN.UTF-8 就不用继续配置
    否则编辑 /etc/locale.gen 文件，将以下配置放开，去除前面的 # 注释就可以，我这里是在165行和505行，如果你和我一样安装的 Ubuntu
en_US.UTF-8 UTF-8

zh_CN.UTF-8 UTF-8

否则的话 Debian 仓库里可能默认没有这个文件，需要安装，然后编辑 /etc/locale.gen 文件把 en_US.UTF-8 UTF-8 放开

sudo apt install -y language-pack-zh-hans
  1. 然后生成语言环境缓存
sudo locale-gen
  1. 执行 echo $LANG 查看是否是 zh_CN.UTF-8，如果不是参考上面可以在 $HOME/.bashrc 或 $HOME/.zshrc 等文件中添加
export LANG=zh_CN.UTF-8

设置默认中文字体

  1. 安装字体文件
    我这里是使用思源黑体/宋体和 Maple Mono NF CN

安装 思源黑体/宋体

sudo apt install -y fonts-noto-cjk fonts-noto-cjk-extra

安装 Maple Mono NF CN
这里选择安装 v7.9，等 v8.0 完善了再安装，可以先安装到 Windows ，解压出来
进入/usr/share/fonts，新建一个文件夹maple-mono-nf-cn，直接把解压出来的所有 .ttf 复制到里面

刷新缓存并验证

fc-cache -fv
fc-list | grep -i "Maple Mono NF CN" | head -5
  1. 修改系统默认字体。添加配置文件 ~/.config/fontconfig/fonts.conf 或 /etc/fonts/local.conf，内容如下：
<?xml version="1.0"?>
<!DOCTYPE fontconfig SYSTEM "fonts.dtd">
<fontconfig>

  <!-- 默认 sans-serif → 思源黑体 -->
  <match target="pattern">
    <test qual="any" name="family"><string>sans-serif</string></test>
    <edit name="family" mode="assign" binding="same">
      <string>Noto Sans CJK SC</string>
    </edit>
  </match>

  <!-- 默认 serif → 思源宋体 -->
  <match target="pattern">
    <test qual="any" name="family"><string>serif</string></test>
    <edit name="family" mode="assign" binding="same">
      <string>Noto Serif CJK SC</string>
    </edit>
  </match>

  <!-- 默认 monospace → Maple Mono NF CN -->
  <match target="pattern">
    <test qual="any" name="family"><string>monospace</string></test>
    <edit name="family" mode="assign" binding="same">
      <string>Maple Mono NF CN</string>
    </edit>
  </match>

</fontconfig>

刷新缓存

fc-cache -fv

验证映射生效，只要这三个都指向了你配置的字体，配置就没问题

fc-match sans-serif
fc-match serif
fc-match monospace

设置完可以再试试使用下面命令看看中文是否正常

yad --title "WSLg Test" --text "WSLg GUI正常！"

  1. 安装 GitHub CLI
  • 添加官方 GPG 密钥，软件源，最后更新并安装，参考官方安装文档
(type -p wget >/dev/null || (sudo apt update && sudo apt install wget -y)) \
	&& sudo mkdir -p -m 755 /etc/apt/keyrings \
	&& out=$(mktemp) && wget -nv -O$out https://cli.github.com/packages/githubcli-archive-keyring.gpg \
	&& cat $out | sudo tee /etc/apt/keyrings/githubcli-archive-keyring.gpg > /dev/null \
	&& sudo chmod go+r /etc/apt/keyrings/githubcli-archive-keyring.gpg \
	&& sudo mkdir -p -m 755 /etc/apt/sources.list.d \
	&& echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/githubcli-archive-keyring.gpg] https://cli.github.com/packages stable main" | sudo tee /etc/apt/sources.list.d/github-cli.list > /dev/null \
	&& sudo apt update \
	&& sudo apt install gh -y
