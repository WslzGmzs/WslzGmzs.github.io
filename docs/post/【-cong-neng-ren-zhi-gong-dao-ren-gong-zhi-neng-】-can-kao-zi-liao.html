基于windows系统的前提

wsl-dashboard

一款现代、高性能、轻量级且低内存占用的 WSL (Windows Subsystem for Linux) 实例管理仪表板。基于 Rust 和 Slint 构建，提供顶级的原生体验。

主要用于隔离环境，多开，WSL所有发行版共享同一个 IP 和同一个网络栈，多开需要注意端口冲突
WSL保姆级全攻略：Windows跑AI Agent，WSL才是终极答案。

ExHyperV

一款图形化的 Hyper-V 管理工具，能让凡人也能轻松玩转Hyper-V的高级功能。

主要用来代替WSL不方便的地方

zcf

零配置,一键搞定 Claude Code & Codex 环境设置 - 支持中英文双语配置、智能代理系统和个性化 AI 助手
